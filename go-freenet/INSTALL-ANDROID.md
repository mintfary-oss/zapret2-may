## 1. Скачать APK

**Способ 1 — браузер на телефоне (быстрее всего):**

Откройте в браузере телефона (Chrome, Firefox, Яндекс):

```
https://github.com/mintfary-oss/zapret2-may/releases/latest/download/freenet-android.apk
```

Нажмите **Скачать** и подождите загрузки (~5–10 МБ).

**Способ 2 — QR-код:** [страница релизов](https://github.com/mintfary-oss/zapret2-may/releases/latest)

**Способ 3 — через ADB (для разработчиков):**

```bash
adb install freenet-android.apk
```

## 2. Разрешить установку из неизвестных источников

APK установлен не из Google Play, поэтому нужно разрешить установку вручную.  
Шаги зависят от производителя. Найдите свой вариант:

### Samsung (Android 10+)
1. **Настройки** → **Биометрия и безопасность** → **Установка неизвестных приложений**
2. Выберите браузер или **Мои файлы** → включите **Разрешить установку**

### Xiaomi / MIUI
1. **Настройки** → **Дополнительные настройки** → **Конфиденциальность** → **Неизвестные источники** — ВКЛ
2. Или при открытии APK нажмите **Настройки** → разрешите для вашего браузера

### Xiaomi / HyperOS (MIUI 14+)
1. **Настройки** → **Специальные возможности** → **Конфиденциальность** → **Установка неизвестных приложений**
2. Выберите приложение, через которое скачали APK → **Разрешить**

### Huawei / EMUI
1. **Настройки** → **Безопасность** → **Дополнительные настройки** → **Установка приложений из внешних источников** — ВКЛ

### OnePlus / OxygenOS
1. **Настройки** → **Дополнительные настройки** → **Конфиденциальность** → **Неизвестные источники** — ВКЛ

### Чистый Android / Pixel
1. **Настройки** → **Приложения** → (выберите ваш браузер) → **Установка неизвестных приложений** → **Разрешить**

> **Совет:** если не можете найти — откройте APK через **Мои файлы** / **Проводник** и следуйте подсказкам системы.

## 3. Установить APK

1. Откройте **Мои файлы** / **Загрузки** и нажмите на `freenet-android.apk`
2. Нажмите **Установить**
3. Если появится предупреждение Google Play Protect — нажмите **Подробнее** → **Установить всё равно**  
   *(Приложение безопасно; Play Protect предупреждает о любом APK не из магазина)*
4. Дождитесь сообщения **"Приложение установлено"**

---

## 4. Первый запуск

1. Откройте **FreeNet** (иконка в лаунчере)
2. Нажмите большую кнопку **ВЫКЛЮЧЕНО** → она станет **ВКЛЮЧЕНО** (зелёная)
3. Появится диалог **"Запрос на подключение VPN"** — нажмите **ОК**
4. В статус-баре появится значок ключа 🔑 — VPN работает
5. Откройте любой сайт, чтобы убедиться что он загружается

> **Что происходит:** FreeNet создаёт VPN-туннель без root через стандартное API Android.  
> Трафик перехватывается внутри устройства и пропускается через движок обхода DPI.  
> Root-права не нужны.

## 5. Настройка Split Tunnel

Split Tunnel позволяет пропускать через FreeNet только выбранные приложения.

### Включить разделённое туннелирование:

1. Откройте FreeNet → нажмите **Split Tunnel**
2. Выберите режим:
   - **Все приложения** (по умолчанию) — весь трафик через FreeNet
   - **Только выбранные** — только указанные приложения
   - **Кроме выбранных** — все, кроме указанных

### Пример: только браузер и Telegram

1. Выберите режим **Только выбранные**
2. В строке поиска введите `Chrome` → поставьте галочку
3. Введите `Telegram` → поставьте галочку
4. Нажмите **Применить**

> **Зачем это нужно:** если нужен обход только для конкретных приложений,  
> а банковские/игровые приложения не требуют прокси — используйте split tunnel.

## 6. Виджет на рабочем столе

FreeNet поддерживает виджет 2×1 для быстрого включения/выключения.

1. Долгое нажатие на рабочем столе → **Виджеты**
2. Найдите **FreeNet** → перетащите виджет на рабочий стол
3. Нажимайте виджет для переключения: зелёный = включён, красный = выключен

---

## 7. Автозапуск при перезагрузке

FreeNet автоматически запускает VPN после перезагрузки устройства, если он был включён.

Если автозапуск не работает:

1. **Настройки телефона** → **Приложения** → **FreeNet** → **Автозапуск** — ВКЛ
2. На Xiaomi/MIUI: **Настройки** → **Приложения** → **Управление приложениями** → **FreeNet** → **Автозапуск** — ВКЛ
3. Убедитесь что приложение не ограничено системным менеджером батареи

## 8. Диагностика

Если что-то не работает — откройте диагностический отчёт:

1. Запустите FreeNet и включите VPN
2. В браузере телефона откройте: `http://127.0.0.1:8080`  
   *(веб-интерфейс FreeNet доступен локально пока VPN включён)*
3. Нажмите вкладку **📊 Диагностика**
4. Нажмите **🔄 Обновить**
5. Нажмите **⬇️ Скачать .txt** — сохранится файл `freenet-report-<дата>.txt`

Отправьте этот файл в Issues: https://github.com/mintfary-oss/zapret2-may/issues

## 9. Частые вопросы

### ❓ VPN включён, но сайты не открываются

**Причина:** провайдер блокирует QUIC (UDP 443) и приложение ждёт таймаута.  
**Решение:** начиная с v1.8.8 это исправлено автоматически.  
Если используете старую версию — обновитесь до последней.

---

### ❓ VPN включён, но YouTube / Instagram грузится медленно

1. Откройте браузер → `http://127.0.0.1:8080`
2. В разделе **Стратегия** выберите **auto (рекомендуется)**
3. Нажмите **🔍 Авто** напротив `youtube.com:443` — программа сама подберёт лучшую стратегию

---

### ❓ Значок VPN пропал после перезагрузки

Включите автозапуск (см. [раздел 7](#7-автозапуск-при-перезагрузке)).

---

### ❓ Появляется "Запрос VPN" после каждого запуска

Это нормальное поведение Android — система запрашивает подтверждение один раз при каждом старте VPN. Это не баг.

---

### ❓ Приложение падает / не запускается

1. **Настройки** → **Приложения** → **FreeNet** → **Хранилище** → **Очистить данные**
2. Перезапустите приложение

---

### ❓ Как обновить приложение?

1. Скачайте новый APK с [страницы релизов](https://github.com/mintfary-oss/zapret2-may/releases/latest)
2. Установите поверх существующего — настройки сохранятся

---

### ❓ Как проверить что VPN действительно работает?

Откройте в браузере https://whatismyipaddress.com — если IP-адрес принадлежит вашему провайдеру, VPN работает как proxy, не меняя IP. FreeNet не скрывает IP — он только обходит DPI-блокировки.

---

### ❓ Не работают банковские приложения с включённым VPN

Некоторые банки блокируют работу через VPN. Решение:

1. Откройте FreeNet → **Split Tunnel**
2. Выберите **Кроме выбранных**
3. Найдите и отметьте банковское приложение

---

### ❓ Высокий расход батареи

VPN-туннель нагружает CPU. Нормальный расход — 2–5% за 8 часов.  
Если больше — проверьте что нет петли ошибок (скачайте диагностику, раздел 8).

## 10. Удаление

1. **Настройки** → **Приложения** → **FreeNet** → **Удалить**
2. Или долгое нажатие на иконку → **Удалить**

После удаления VPN-профиль удаляется автоматически.
